# RTL8723BE old-TRX PCIe 32-bit DMA interval and TX rollback
Date: 2026-10-10. Status: SOURCE-ONLY PARTIAL; HP native compilation / runtime OPEN.

## Reference and invariant
Frozen rtlwifi/rtl8723be PCIe DMA profile:
torvalds/linux@fd179f8a05be3ccae366b9b96e176b51fbe54aab.
Frozen NetBSD bus_dma and the opt-in driver:
NetBSD/src@03d918f6d0e81fa05b8f1160eca0628ad39988a6.

RTL8723BE Linux module default dma64=false. The NetBSD adapter
has an actual 0..0xffffffff bus_dmatag_subregion in
src/rtwn8723be_netbsd.c. The hardware descriptors still accept only
32-bit bus addresses. Checking the start address alone is insufficient
if a corrupted/wrong-segment DMA map escapes the subregion: the entire
descriptor or packet interval must remain within the 32-bit aperture.
Valid means length > 0, start <= UINT32_MAX and length - 1 <=
UINT32_MAX - start, with subtraction to avoid addition overflow.
