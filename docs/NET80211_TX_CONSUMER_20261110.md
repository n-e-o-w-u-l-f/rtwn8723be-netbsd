## Implemented behavior

The existing if_start retains its datapath TX-start lease across the native
consumer. The non-MPSAFE ifnet and NET softint use kernel serialization and
splnet. No stack callback, software crypto or queue kick executes under the
descriptor TX mutex.

Fresh management traffic is dequeued before normal Ethernet data. Management
uses and clears the stack-supplied node context; Ethernet data acquires a node
through ieee80211_find_txnode and is encapsulated by ieee80211_encap. Failure
paths respect which real NetBSD APIs have already consumed the mbuf.
Unsupported fragment lists are released completely, with the node released once.

The preparation path allocates one independent, exclusively writable and
contiguous mbuf with exact cipher header/trailer room. This prevents the
inspected NetBSD ieee80211_crypto_encap API from replacing its pointer-by-value
head through M_PREPEND or m_pullup. Protected frames require a valid transmit
software AES-CCM key; no hardware CAM/offload encryption is substituted. Ordinary
privacy data cannot silently fall back to cleartext; initial clear EAPOL is
permitted, and protected EAPOL follows the same real software-CCMP path.
A consumed CCMP packet number is never rolled back after a cipher error.

Successful DMA submission transfers both packet and referenced node to the
existing native TX slot. EBUSY retains the already prepared packet/node pair;
completion retries it without encapsulation or encryption again. Every observed
completion-before-OACTIVE wake is honored, including repeated races on later
frames. Native wake and an optional external completion notification share one
published callback lifetime lease, even when the external callback is NULL.

Real key-update hooks are wrapped and later restored. Epoch/depth guards and
saved BSS, current channel/frequency/flags, state, default key, mode and privacy
context reject stale pending ciphertext, including replacement of a key in the
same slot. STA data must still address the actual current BSS. Hooks do not
take the TX mutex, purge packets or enter TX; native reclaim can delete keys
while that mutex is already held.

Legacy rate selection validates negotiated rates and fixed-rate membership.
RTS threshold includes on-air FCS and overrides ERP CTS-only; ERP uses the
configured CTS/RTS policy. A required control rate must be a legal negotiated
BASIC legacy rate, no faster than the frame or the pinned Linux 24-Mbps ceiling;
ERP, 11B and channel 14 additionally require CCK. Missing compatible coverage is
an error, not an invented control rate. Rate/protection selection runs after all
potentially reentrant BPF callbacks, immediately before context validation and DMA.

STOP first revokes ifnet RUNNING admission. An active TX consumer/key update or
failed/false-success hardware STOP retains ownership. Only an allowed unstarted
quiescent state or independently verified STOPPED state may purge the pending
pair. Unregister drains asynchronous owners before restoring key hooks and
detaching net80211. Genuine hw_start/hw_stop methods remain mandatory.
