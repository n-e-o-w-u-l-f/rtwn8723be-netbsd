# NetBSD deferred TX producer initialization

Scope: COV-RTL-014/009, source-only; full port and native WLAN acceptance OPEN.
Base: 0c8f1f5522cef1538f78ef44100b081c01671524.

## Finding and correction

TX completion invokes if_schedule_deferred_start, but registration never called
if_deferred_start_init. Frozen NetBSD asserts a non-NULL deferred-start pointer;
with assertions disabled, a nonempty send queue reaches a NULL dereference.
Allocate the default deferred producer after interface/receive-queue setup and
before if_register publishes the interface. NetBSD owns its destruction in
if_detach. The existing successful hardware-stop prerequisite remains intact;
a failed stop retains the registered interface and producer.

Primary reference: [NetBSD if.c at frozen revision](https://github.com/NetBSD/src/blob/03d918f6d0e81fa05b8f1160eca0628ad39988a6/sys/net/if.c),
if_schedule_deferred_start, if_deferred_start_init and if_detach.
Linux completion reference: [frozen rtlwifi pci.c](https://github.com/torvalds/linux/blob/fd179f8a05be3ccae366b9b96e176b51fbe54aab/drivers/net/wireless/realtek/rtlwifi/pci.c),
_rtl_pci_tx_isr reclaims descriptors and wakes transmit queues when capacity returns.
The allocation is a NetBSD integration requirement, not a Linux hardware change.

## Remaining gap and safe state

A separate management-only wake gap remains: frozen if_schedule_deferred_start
returns early when the Ethernet if_snd is empty; the driver's ic_mgtq can still
contain frames after ring backpressure. Initialization does not resolve that
queue mismatch. Follow-up must preserve producer-lock ordering and detach/IRQ
rundown while ensuring management-only restart, with native stress validation.
Software crypto is deliberately selected by the adapter; hardware CAM offload,
WPA2 association, physical RX/TX, PM and recovery acceptance remain open.
No compiler, HP command, source update, kernel installation, boot or network
change occurred. The earlier HP fast-forward refusal remains EXTERNAL_BOUNDARY /
NOT_RUN; this source patch does not grant permission to retry it. Last reported
safe HP kernel is F77; current boot was not reobserved. No paid runner used.
